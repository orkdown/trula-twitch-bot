# Trula Twitch Chat Bot 🎵

Легковесный и отказоустойчивый чат-бот для Twitch, интегрированный со стримерским музыкальным сервисом **Trula** (через Trula Public REST API и WebSocket в реальном времени).

## Возможности

* 📖 **`!help` / `!команды` / `!помощь`** — краткий список доступных музыкальных команд в чате.
* 🎵 **`!song` / `!np` / `!трек` / `!музыка`** — показывает текущий трек, никнейм зрителя (который заказал его за баллы канала) и тайминги/длительность.
* 📋 **`!queue` / `!очередь`** — список следующих треков в очереди.
* 🔗 **`!yt` / `!songlink` / `!ссылка`** — прямая ссылка на YouTube-видео играющего трека.
* 🔄 **`!link <url/текст>` / `!convert` / `!к`** — конвертер ссылок из **Spotify, Яндекс Музыки, Apple Music, VK, SoundCloud, Deezer** или поиск по названию в YouTube-ссылку для заказа за баллы канала.
* 🤖 **Авто-конвертер в наградах за баллы:** если зритель отправляет в награду ссылку на трек из Spotify/Яндекса/ВК или просто текст "Исполнитель - Трек", бот моментально находит официальный клип на YouTube и присылает готовую ссылку для заказа!
* ⏭️ **`!skip` / `!скип`**:
  * **Стример и модераторы** — мгновенный пропуск трека.
  * **Зрители (Vote-Skip)** — голосование за пропуск трека (по умолчанию нужно 3 голоса; настраивается в `.env`).
* 📺 **HUD Виджет для OBS (`/hud`):** стильный полупрозрачный виджет с градиентом от обложки, индикацией паузы, бегущей строкой, эквалайзером и таймингами реального времени.
* 🎙️ **AI-DJ Голосовой радиоведущий:** автоматическая драйвовая озвучка (в стиле Record / DFM) новых заказов за баллы и каждого ~5 трека из плейлиста прямо в OBS с поддержкой Microsoft Neural TTS (голос Дмитрий) и Google Gemini.
* 🎛️ **Web-UI Пульт управления (`/remote`):** адаптивный мобильный и десктопный пульт для стримера (Play/Pause, Skip, ручной вызов AI-DJ, управление очередью, поиск и конвертер треков) с защитой PIN-кодом.

## Настройка

1. Откройте файл `.env`:
   ```ini
   # Токен публичного API Trula:
   TRULA_TOKEN=your_trula_token_here

   # Имя вашего Twitch-канала:
   TWITCH_CHANNEL=your_channel_name

   # Имя аккаунта бота (можно использовать ваш основной ник):
   TWITCH_BOT_USERNAME=your_bot_username

   # OAuth-токен чата (получить на https://twitchtokengenerator.com с правами chat:read, chat:edit):
   TWITCH_BOT_OAUTH=oauth:your_oauth_token_here

   # Сколько голосов зрителей требуется для !skip (0 - только стример и модеры):
   VOTE_SKIP_THRESHOLD=3

   # PIN-код для доступа к веб-пульту стримера (/remote):
   REMOTE_PIN=1580
   ```
2. Если `TWITCH_BOT_OAUTH` не заполнен, бот автоматически подключится в **режиме только для чтения** (будет слушать чат и логировать ответы в консоль).

## Запуск

* **Быстрый запуск:** дважды кликните по `start.bat`
* **Либо через консоль:**
  ```bash
  node index.js
  ```
