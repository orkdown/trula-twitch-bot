# Trula Twitch Chat Bot 🎵

Легковесный и отказоустойчивый чат-бот для Twitch, интегрированный со стримерским музыкальным сервисом **Trula** (через Trula Public REST API и WebSocket в реальном времени).

## Возможности

* 🎵 **`!song` / `!np` / `!трек` / `!музыка`** — показывает текущий трек, никнейм зрителя (который заказал его за баллы канала) и тайминги/длительность.
* 📋 **`!queue` / `!очередь`** — список следующих треков в очереди.
* 🔗 **`!yt` / `!songlink` / `!ссылка`** — прямая ссылка на YouTube-видео играющего трека.
* 🔄 **`!link <url>` / `!convert <url>` / `!к <url>`** — конвертер ссылок из **Spotify, Яндекс Музыки, Apple Music, VK, SoundCloud, Deezer** в YouTube-ссылку для заказа за баллы канала.
* 🤖 **Авто-конвертер в чате:** если зритель просто отправляет ссылку на трек из Spotify/Яндекса/ВК в чат, бот автоматически распознает её, найдёт официальный YouTube-клип и пришлёт ссылку, готовую для вставки в награду за баллы!
* ⏭️ **`!skip` / `!скип`**:
  * **Стример и модераторы** — мгновенный пропуск трека.
  * **Зрители (Vote-Skip)** — голосование за пропуск трека (по умолчанию нужно 3 голоса; настраивается в `.env`).
* 🚨 **`!emergency` / `!panic`** — аварийная кнопка для модераторов: моментально скрывает видео на стриме в виджете OBS при запрещённом контенте.

## Настройка

1. Откройте файл `.env`:
   ```ini
   # Токен публичного API Trula:
   TRULA_TOKEN=your_trula_token_here

   # Имя вашего Twitch-канала (например, orkdown):
   TWITCH_CHANNEL=orkdown

   # Имя аккаунта бота (можно использовать ваш основной ник):
   TWITCH_BOT_USERNAME=orkdown

   # OAuth-токен для отправки сообщений в чат (получить в 1 клик на https://twitchapps.com/tmi/):
   TWITCH_BOT_OAUTH=oauth:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

   # Сколько голосов зрителей требуется для !skip (0 - только стример и модеры):
   VOTE_SKIP_THRESHOLD=3
   ```
2. Если `TWITCH_BOT_OAUTH` не заполнен, бот автоматически подключится в **режиме только для чтения** (будет слушать чат и логировать ответы в консоль).

## Запуск

* **Быстрый запуск:** дважды кликните по `start.bat`
* **Либо через консоль:**
  ```bash
  node index.js
  ```
